# 🛴 WhatTheMyBoltSamoket 🇺🇦

Інтерактивна веб-платформа для моніторингу електросамокатів **Bolt** по всіх районах міст України з підтримкою фотореалістичного режиму **Google Maps (Супутник 3D/HD)**, **Google Street View 360°**, заторів та бронювання.

## 🌟 Особливості проекту

- 🏙️ **Повне покриття всіх районів міст України**:
  - **Київ**: усі 10 адміністративних районів (Шевченківський, Печерський, Подільський, Оболонський, Голосіївський, Солом'янський, Святошинський, Дарницький, Дніпровський, Деснянський / Троєщина).
  - **Львів**: усі 6 районів (Галицький, Франківський, Сихівський, Личаківський, Шевченківський, Залізничний).
  - **Одеса**: усі 4 райони (Приморський, Київський / Таїрова, Хаджибейський, Пересипський).
  - **Дніпро**: усі 6 районів (Центральний, Соборний, Шевченківський, Чечелівський, Новокодацький, Індустріальний / АНД).
  - **Харків**, **Вінниця**, **Івано-Франківськ**, **Полтава**.
- 🗺️ **Стилізація під Google Maps**:
  - **Реалістичний режим (Google Супутник 3D/HD)** за замовчуванням.
  - Швидке перемикання між **«Схема Google»** та **«Супутник»**.
  - **🚦 Живий шар заторів Google Maps (Live Traffic)**.
- 🌐 **Google Street View 360°**:
  - Натискання на самокат дозволяє в 1 клік відкрити реальну **360° панораму вулиці**, де припарковано обраний самокат.
- ⚡ **Меню керування самокатом**:
  - **Забронювати самокат** на 15 хвилин з оновленням статусу.
  - **Подати звуковий сигнал (Ring)** з імітацією через Web Audio API.
  - **Пішохідний маршрут** у Google Maps від вашої поточної геолокації.
  - **Калькулятор вартості поїздки** за тарифами Bolt (9 ₴ старт + 3.80 ₴/хв).
- 📊 **Аналітика районів**:
  - Статистика по кожному району: кількість самокатів, середній заряд акумулятора, вільні самокати.
- 🔌 **Гібридне джерело даних**:
  - Реалістичний генератор парку самокатів прямо з коробки.
  - Вбудований бекенд-проксі для підключення живого **Bolt Production API**.

## 🛠️ Стек технологій

- **Frontend**:
  - React 18, Vite
  - Tailwind CSS (з фірмовими неоновими кольорами Bolt `#34D186`)
  - Leaflet з кастомними SVG-маркерами та тайлами Google Maps
  - Lucide Icons
- **Backend**:
  - Node.js, Express
  - Axios, CORS
  - Сервіс симуляції руху та розрахунку батарей
  - Клієнт взаємодії з мобільним API Bolt

## 🚀 Швидкий запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/<ваш-логін>/WhatTheMyBoltSamoket.git
cd WhatTheMyBoltSamoket
```

### 2. Встановлення залежностей
```bash
# Встановлення для сервера
cd server
npm.cmd install

# Встановлення для клієнта
cd ../client
npm.cmd install
cd ..
```

### 3. Запуск проекту
Найпростіший запуск у Windows — двічі клікнути на файл:
```powershell
.\start.bat
```

Або через термінал:
```powershell
node server/src/index.js
```

Після запуску відкрийте браузер:
👉 **http://localhost:3001**
